# Lecture Recorder

초경량 스마트 강의 녹음 및 AI 요약 웹 앱. Next.js(App Router) + Tailwind CSS + Google Gemini API로 만들었습니다.

## 핵심 아이디어

- **오디오는 기기에, 텍스트는 브라우저에.** 녹음/업로드한 강의 오디오는 Opus로 압축되어 기기 다운로드 폴더에 저장됩니다. 브라우저의 IndexedDB에는 오디오 blob이 아니라 스크립트·요약본·강의노트·체크리스트 같은 텍스트 메타데이터만 영구 보관됩니다.
- **화면을 다시 열면** IndexedDB에서 메타데이터를 즉시 복원하고, 오디오 재생이 필요하면 사용자가 다운로드 폴더에서 같은 파일을 다시 선택해 붙입니다(재첨부).

## 화면 구조 (3단계 네비게이션)

Next.js 라우트는 `/` 하나뿐이며, 아래 3단계는 모두 클라이언트 상태(`screenStack`)로 전환되는 단일 페이지 앱입니다.

1. **카테고리 앨범 (albums)** — 카테고리별 앨범 카드와 이번 주 통합 체크리스트 대시보드를 한 화면에서 보여줍니다.
2. **카테고리별 녹음 목록 (category)** — 선택한 카테고리에 속한 녹음들을 목록으로 보여주고, 새 녹음을 시작할 수 있습니다.
3. **녹음 상세 복습 (detail)** — 오디오 재생, AI 요약본/상세 강의노트/체크리스트, 북마크, 심화 탐구 질의를 한 화면에서 다룹니다.

## AI 기능 (Google Gemini)

- **빠른 개요**: 음성만을 기반으로 한 3~5줄 AI 요약본.
- **상세 강의노트**: 음성 + 첨부 참고자료(PDF/TXT/이미지)를 통합 분석해 시험 대비용 노트를 생성합니다. 중요도에 따라 🔥(핵심/출제 포인트), 💡(자료 보충 개념), 🗣️(교수님 코멘트/사례) 태그가 붙고, 마크다운 제목·표·굵게 서식을 지원합니다.
- **체크리스트**: 음성 속 공지/과제와 참고자료 속 과제를 통합해 실천 항목 목록을 생성합니다.
- **심화 탐구**: 강의노트 하단에서 추가로 궁금한 개념을 질문하면, Gemini가 정의·심층 설명·예시를 담은 제안 블록을 생성합니다. 이 제안은 **중앙에서 보기(Center Peek) 검수 모달**에서 블록별로 확인합니다 — **v(확정) / x(취소) / +(피드백 추가 후 재질의)** 로 검토한 뒤, 확정된 블록만 강의노트의 알맞은 위치에 병합됩니다.

대용량 강의(2~3시간 분량)와 큰 첨부 자료는 Gemini Files API를 통해 업로드되므로 긴 녹음도 안정적으로 처리됩니다.

## 기술 스택

- Next.js 15 (App Router), React 19, Tailwind CSS 4
- `@google/genai` (Gemini API — STT/요약/강의노트/체크리스트/심화 탐구)
- 브라우저 IndexedDB (메타데이터 저장), `MediaRecorder`(Opus 인코딩)

## 로컬 실행

1. [Node.js 20+](https://nodejs.org/)를 설치합니다.
2. 이 폴더에서 `.env.local` 파일을 만들고 Gemini API 키를 설정합니다.

```bash
GEMINI_API_KEY=your-api-key-here
```

3. 의존성 설치 후 개발 서버를 실행합니다.

```bash
npm install
npm run dev
```

4. [http://localhost:3000](http://localhost:3000) 에서 확인합니다.
